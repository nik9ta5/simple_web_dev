# Читалка

* Серверная часть реализована на Python (FastAPI)
* В файле `requirements.txt` приведены требуемые зависимости
* Главы книги находятся в `static/`
* Сохранение прогресса для каждого устройства происходится в .json файл

## Запуск
1. Создать виртуальное окружение, при желании:
```bash
python -m venv venv
```

2. Активировать виртуальное окружение
```bash
source venv/bin/activate
```

3. Установка зависимостей
```bash
pip install -r requirements.txt
```

4. Запуск приложения:
```bash
uvicorn main:app --reload
```

## Использование
После запуска приложение будет доступно: `http://127.0.0.1:8000`

* Авторизация не реализована. 
* Сохранение прогресса чтения (по главам) представлено в .json файле.
* Чтобы поделиться прогрессом чтрения нажать на кнопку "Поделиться" (откроется поле с url, который можно скопировать и открыть на новом устройстве). 
* Если на "новом" устройстве пролистать до новой главы, при открытии на первом устройстве процресс изменится.
